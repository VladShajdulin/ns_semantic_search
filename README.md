\# План проекта

1\) В jupyter notebook написать парсер, сохранять все в json файл. Буду парсить следующую информацию: названия статей, ссылки, авторов, дату публикации, тэги, индекс важности, и главное - аннотации, по ним будет происходить поиск.

2\) В jupyter notebook реализовать функцию семантического поиска по аннотациям. MVP - эмбеддинги статей и рейтинг по косинусной близости.

3\) Оформить все в виде готового кода на python, в котором прописать класс базы статей и методы. Класс будет инициализироваться через json файл и содержать методы для поиска на основе раннее реализованной функции. Результат поиска - объект другого класса, который имеет методы для сортировки и фильтрации результатов (в будущем).

4\) Обернуть все Docker. Я пока слабо представляю, как это работает, но планирую изучить.



\# Дальнейшая работа

1\) Реализация векторной базы данных.

2\) Подключение готового проекта к телеграм боту.

3\) Реализация схемы с reranking.

4\) Создание в jupyter notebook синтетического датасета для подсчета метрик ранжирования и обучения reranker-модели.

5\) "Умное" ранжирование с учетом индекса важности и свежести статьи.

6\) Реализация функционала с фильтрацией, параметры фильтрации также можно будет парсить из поискового запроса в телеграм боте.

7\) Функция рекомендации похожих статей на основе результатов семантического поиска
